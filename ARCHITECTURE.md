# Querywell architecture

Native macOS (14+) database client. Swift 6 (language mode 6, strict concurrency), SwiftUI + AppKit.

## Layout

```
Querywell/
  project.yml              XcodeGen spec (source of truth for the Xcode project; also holds version/build)
  Querywell.xcodeproj/     generated by `xcodegen generate` (gitignored)
  docker-compose.yml       integration servers: MySQL 8.4, MariaDB 11.4, Postgres 16 (TLS), SSH bastion
  docker/ssh/              bastion image for the SSH tests
  design/                  DESIGN_NOTES.md + HTML mockups of the approved canvas (reference only)
  docs/screenshots/        downscaled snapshot PNGs used by README.md
  App/
    Sources/               macOS app target "Querywell" - UI only, no business logic
      QuerywellApp.swift   App entry, scenes, menu commands
      Model/               AppModel, ConnectionWorkspace (one per window), window actions, Docker fixtures (Debug)
      Launcher/            connections launcher (sidebar, cards)
      Editor/              connection editor sheet
      Workspace/           connection window, in-window tab strip, window support
      QuickSwitcher/       Cmd-K palette
      Browser/             schema sidebar, data grid, filters, structure views, row inspector, edit review, batch ops
      Query/               SQL editor (TextKit 2), query tab, results, explain, history/saved/snippets sidebar
      AI/                  assistant panel and model
      DataEditors/         JSON and PHP-serialized value editors
      SearchReplace/       search & replace sheet
      Console/             SQL console and SSH terminal tabs
      DataTransfer/        export, import and result-export sheets
      Safety/              WriteGate and the confirmation sheet
      Settings/            Settings window
      Design/              Theme tokens and shared components
    Resources/             Assets.xcassets (AppIcon, AccentColor), Info.plist, Querywell.entitlements
    Tests/                 QuerywellTests (app-level model, flow and snapshot tests)
  Packages/Core/           Swift package "Core", library product "QuerywellCore"
    Sources/QuerywellCore/
      Connections/         profiles, repository (JSON), draft/validator, opener/tester, LiveConnection
      Secrets/             SecretStore protocol, KeychainSecretStore, InMemorySecretStore
      Persistence/         AppDirectories, atomic JSON file I/O
      Settings/            AppSettings + store
      Drivers/             DatabaseDriver protocol; MySQL/ (MySQLNIO) and Postgres/ (PostgresNIO)
      SSH/                 system-ssh tunnels, askpass, terminal command, loopback ports
      Schema/              inspectors (MySQL, Postgres), SQLDialect, filters, distinct values
      Editing/             SQL lexer/splitter/classifier, WriteGuard, EditSession (transactional edits)
      Browser/             cell parsing, column presentation, grid interactions, edit review model
      Query/               QueryRunner, history, saved queries, snippets, completion, highlighter, formatter, explain
      Maintenance/         batch engine/collation planner and runner
      Parsers/             PHP serialized, JSON document, safe replace
      SearchReplace/       database-wide search & replace (dry run, keyset pagination)
      ImportExport/        Dump/ (export planner/runner, import runner, gzip, tools, table selection),

      Console/             console input, editor, formatter, completion

    ci.sh                  full build + test, warnings as errors (the phase gate)

    release.sh             Developer ID sign + notarize + staple + DMG/zip + checksums -> build/release/

    make-icon.swift        regenerates the placeholder AppIcon.appiconset
```

## Rules

- **All non-UI logic lives in Core** and is unit-tested. The App target only renders state and forwards intents.
- **Secrets never touch disk outside the Keychain.** `ConnectionProfile` and friends contain *no* secret fields; secrets are addressed by `SecretKey(ownerID:kind:)` through `SecretStore`.
- **Concurrency:** model types are `Sendable` value types. Stateful services are `actor`s (e.g. `ConnectionRepository`). No `@unchecked Sendable` without a comment justifying it.
- **Driver layer** (Phase 2) is protocol-based (`DatabaseDriver`) so SQLite/others can be added later; `DatabaseEngine` is an open enum switch point.
- **Testing:** Swift Testing (`import Testing`) for Core. Integration tests that need Keychain/Docker skip gracefully when unavailable.
- **Warnings are errors** in CI (`scripts/ci.sh`).
- Persistence format is versioned JSON (`schemaVersion`) in `~/Library/Application Support/Querywell/`.
