# Querywell architecture

Native macOS (14+) database client. Swift 6 (language mode 6, strict concurrency), SwiftUI + AppKit.

## Layout

```
Querywell/
  project.yml              XcodeGen spec (source of truth for the Xcode project)
  Querywell.xcodeproj/     generated by `xcodegen generate` (gitignored)
  App/
    Sources/               macOS app target "Querywell" — UI only, no business logic
    Resources/             Assets.xcassets, Info.plist, Querywell.entitlements
    Tests/                 QuerywellTests (thin app-level tests)
  Packages/Core/           Swift package "Core", library product "QuerywellCore"
    Sources/QuerywellCore/
      Connections/         ConnectionProfile & friends, ConnectionRepository (JSON)
      Secrets/             SecretStore protocol, KeychainSecretStore, InMemorySecretStore
      Persistence/         AppDirectories, atomic JSON file I/O
      (later) Drivers/ SSH/ Query/ Parsers/ AI/ ImportExport/
    Tests/QuerywellCoreTests/
  scripts/
    ci.sh                  full build + test, warnings as errors (the phase gate)
```

## Rules

- **All non-UI logic lives in Core** and is unit-tested. The App target only renders state and forwards intents.
- **Secrets never touch disk outside the Keychain.** `ConnectionProfile` and friends contain *no* secret fields; secrets are addressed by `SecretKey(ownerID:kind:)` through `SecretStore`.
- **Concurrency:** model types are `Sendable` value types. Stateful services are `actor`s (e.g. `ConnectionRepository`). No `@unchecked Sendable` without a comment justifying it.
- **Driver layer** (Phase 2) is protocol-based (`DatabaseDriver`) so SQLite/others can be added later; `DatabaseEngine` is an open enum switch point.
- **Testing:** Swift Testing (`import Testing`) for Core. Integration tests that need Keychain/Docker skip gracefully when unavailable.
- **Warnings are errors** in CI (`scripts/ci.sh`).
- Persistence format is versioned JSON (`schemaVersion`) in `~/Library/Application Support/Querywell/`.
