# Decisions

Defaults chosen where the brief left room. Each is cheap to revisit unless noted.

| # | Date | Decision | Why |
|---|------|----------|-----|
| 1 | 2026-10-26 | Xcode project generated by **XcodeGen** from `project.yml`; `.xcodeproj` is gitignored and regenerated by `scripts/ci.sh`. | Diffable, merge-friendly project definition; agents can edit YAML safely. Run `xcodegen generate` before opening in Xcode. |
| 2 | 2026-10-26 | Bundle ID `com.jeremyhaber.Querywell`. Keychain service name is a separate constant `com.jeremyhaber.Querywell.secrets`. | Placeholder owner prefix; change before first public release (keychain service is decoupled so a bundle-ID change won't orphan secrets). |
| 3 | 2026-10-26 | Core package product named `QuerywellCore` (package dir `Packages/Core`). | Avoids clashing with generic `Core` module names in dependencies. |
| 4 | 2026-10-26 | **Swift Testing** for new tests (XCTest only where required by Xcode UI tests). | Modern, parallel, ships with Xcode 26 toolchain. |
| 5 | 2026-10-26 | Keychain: legacy file-based login keychain (`kSecClassGenericPassword`, no data-protection keychain). | Data-protection keychain needs a keychain-access-group entitlement + signing; that breaks `swift test`. Can migrate later. |
| 6 | 2026-10-26 | Connection metadata in a single `connections.json` (`schemaVersion: 1`) containing profiles + folders, written atomically. | Simple, human-inspectable; small data size. |
| 7 | 2026-10-26 | Local builds sign ad-hoc (`CODE_SIGN_IDENTITY=-`); hardened runtime ON; App Sandbox OFF. Developer ID signing deferred to `scripts/release.sh` (Phase 8). | Per brief; lets CI build without a team ID. |
| 8 | 2026-10-26 | Private GitHub repo `jeremyhaber/Querywell`, default branch `main`; push at end of each phase. | Jeremy approved creating the repo. |
| 9 | 2026-10-26 | Design canvas provided (see `design/DESIGN_NOTES.md`); snapshots committed under `design/project/`. Mockup web fonts (Inter/JetBrains Mono) map to SF Pro/SF Mono natively. | Canvas is the visual source of truth; native fonts per brief. |
| 10 | 2026-10-26 | `LM_SKIP_METADATA_EXTRACTION=YES` (project.yml + ci.sh command line). | Silences Xcode's AppIntents "metadata extraction skipped" noise warning, incl. on SwiftPM test bundles that ignore project settings. Remove if we ever adopt App Intents. |
| 11 | 2026-10-26 | `ConnectionRepository` mutations are transactional: applied to a copy, committed in memory only after the atomic disk write succeeds. Profile secrets are deleted *after* the profile is persisted as removed (orphaned secret is preferable to a profile missing its password). | Memory and disk never diverge on I/O failure. |
| 12 | 2026-10-26 | App Support dir created `0700`, `connections.json` `0600`. Production profiles require write confirmation but are not forced read-only (`readOnly` is a separate opt-in). | Least-privilege file perms; brief separates PROD guard from read-only mode. |
| 13 | 2026-10-26 | **SSH via system OpenSSH** (`/usr/bin/ssh -L`, password/passphrase via `SSH_ASKPASS_REQUIRE=force`) instead of Citadel, behind the `SSHTunnelProvider` protocol. | Brief allows the `ssh -L` fallback. System ssh natively handles 1Password/agent sockets, `~/.ssh/config` (ProxyJump, aliases), known_hosts verification, every key format; the same binary powers the Phase 7 terminal and remote mysqldump, so one SSH stack. Citadel can be added as a second provider later. |
| 14 | 2026-10-26 | Host keys: `StrictHostKeyChecking=accept-new` against the user's known_hosts (trust on first use); a *changed* key is a hard failure surfaced as `hostKeyMismatch`. | Matches Sequel Ace/ssh defaults without silently accepting MITM. |
| 15 | 2026-10-26 | Integration servers via `docker-compose.yml` on high ports (MySQL 8.4 :13306, MariaDB 11.4 :13307, Postgres 16 :15432 with TLS, Alpine sshd bastion :12222). Tests run only when `QUERYWELL_INTEGRATION=1` (set by `scripts/integration.sh`); SSH test keys generated per machine into `build/test-ssh/`, never committed. | Avoids clashing with local DBs; no private keys in git (GitHub push protection). |
| 16 | 2026-10-26 | Drivers use one shared NIO `EventLoopGroup` (`MultiThreadedEventLoopGroup.singleton`). Statements run one at a time per session; parallel work opens more sessions. | Mirrors a real client connection; avoids interleaving on one wire. |
| 17 | 2026-10-26 | Collation rewrite is a streaming DDL-only transform in Core (`CollationRewriter`), usable on both export and import; default "keep original". | Fixes cross-provider "Unknown collation" imports without risking data bytes; import-side fix covers dumps made elsewhere. |
| 18 | 2026-10-26 | "Batch update table type" interpreted as storage engine (`ENGINE=`); batch charset/collation conversion added alongside. Lives in the table browser (Phase 4). | MySQL historically called the engine "table type" (`TYPE=`). **Confirmed by Jeremy 2026-10-26.** |
| 19 | 2026-10-26 | Zero-warning gate applies to **our** code/config. `ci.sh` reports but doesn't fail on warnings unambiguously from SwiftPM checkouts (e.g. swift-nio's legacy `NIO`/`CNIOWindows` targets under Xcode 26's dependency scan). `swift build/test -Xswiftc -warnings-as-errors` still applies to all Core sources. | We can't fix upstream package manifests; failing on them would block every phase. Filter is narrow and covered by a classifier check. After #20 the clean build has 0 warnings; the filter is now a safety net. |
| 20 | 2026-10-26 | Core tests run via `swift test` only (not in the Xcode scheme); `QuerywellTests` reaches Core through the host app instead of linking it. | Linking the package in both app and test bundle forces dynamic package frameworks and caused a link-order race (Crypto). |
| 21 | 2026-10-26 | Known driver caveats: Postgres zero-row SELECTs re-run as `SELECT * FROM (…) LIMIT 0` to fetch columns (plain SELECT/WITH only); Postgres composite/geometric types arrive as bytes; MySQLNIO asserts on late pipeline errors in Debug builds. Revisit in Phase 5 (query editor). | Limits of MySQLNIO 1.9 / PostgresNIO 1.33 APIs; documented rather than hidden. |
| 22 | 2026-10-26 | Tunnelled connects race the driver handshake against ssh's "channel N: open failed" (tunnels log at `LogLevel=INFO`); tunnels retry on a fresh local port if ssh reports "Address already in use"; `LoopbackPort` never hands out the same port twice in quick succession. | Unreachable DB behind a bastion fails in <1s with ssh's real reason instead of a 15s timeout; concurrent window opens can't collide on ports. |
| 23 | 2026-10-26 | "Test connection" lives in Core (`ConnectionTester`, supports unsaved profiles via secret overlay); the button itself ships with the connection editor in Phase 3. | No connection editor UI exists yet. |
| 24 | 2026-10-26 | Tabs inside a connection window are an **in-window tab strip** (per design `Main.dc.html`), not NSWindow native tabbing. Native window tabbing is disabled for connection windows. | The design puts tabs under the connection header with per-kind dots; NSWindow tabs would duplicate the toolbar per tab and fight one-window-per-connection. |
| 25 | 2026-10-26 | Opening an already-open connection focuses its window by default; Settings → General can switch to "always new window" (and ⌥-Connect opens a second window). | Avoids accidental duplicate PROD sessions while still allowing two windows. |
| 26 | 2026-10-26 | Launcher filtering, ⌘K fuzzy ranking, tab state and the connection-editor draft live in Core as pure models; SwiftUI views stay thin. | Keeps UI logic unit-testable per ARCHITECTURE.md. |
| 27 | 2026-10-26 | Connection toolbar: identity and actions use `.automatic` placement with a `ToolbarSpacer(.flexible)` on macOS 26 (`.navigation`/`.primaryAction` on 14–15), the system title is removed (`.toolbar(removing: .title)` on 15+), and header density follows window width (engine label < 1040pt, quick-open text < 960pt). A snapshot test asserts no toolbar overflow at 1200/1000/820pt. | The stray glass circle Jeremy saw was AppKit's toolbar overflow button: `.navigation` items are width-capped on macOS 26 and the hidden title still took space. |
| 28 | 2026-10-26 | Snapshot harness (`scripts/snapshots.sh`) captures real window-server output of the app's own windows and waits with `await Task.sleep`, never `RunLoop.run`. | `cacheDisplay` mis-draws macOS 26 glass, and a blocking run loop starves the main actor so SwiftUI never finishes layout — both produced false artefacts. |
| 29 | 2026-10-26 | Table namespace = `TableRef(schema:name:)`: MySQL/MariaDB *database* or Postgres *schema* in the session's current database; switching Postgres databases reconnects the window. All generated SQL goes through `SQLDialect` (identifier/literal quoting); MySQL sessions strip `NO_BACKSLASH_ESCAPES` from the session `sql_mode` on connect so literal escaping is always valid. | One addressing model for both engine families; a single choke point for quoting prevents injection. |
| 30 | 2026-10-26 | Write guard: PROD writes always confirm (setting can't disable it); read-only beats PROD; unknown statements are write+destructive; `CALL`/`DO`/`EXECUTE` are destructive (opaque, no dry-run → typed DB name on PROD); dry-run counts only for single-table DELETE/UPDATE, otherwise "Can't estimate". Inline edits commit in one transaction with optimistic-concurrency WHERE on original values (floats/geometry excluded). | Conservative by default: a wrong "safe" classification on PROD is the expensive failure. |
| 31 | 2026-10-26 | Saved queries are stored per connection profile (or global) in `saved-queries.json`. Query history is per connection with bounded retention, defaults: 1,000 entries, 90 days, 2 MB per connection; statements over 64 KB stored truncated (open-only, not re-runnable); consecutive duplicates bump a run count. Deleting a connection purges its history and saved queries. Re-running from history goes through the normal runner + write guard. Limits are adjustable in Settings with a Clear History button. | Jeremy asked for saved queries on the profile and rerunnable history without unbounded local storage. |
| 32 | 2026-10-26 | `WriteOrigin.gridEdit`: on PROD, single-row PK-targeted UPDATEs from grid/inspector edits need a confirmation click with the exact SQL; grid DELETEs and any free-form UPDATE/DELETE still require typing the database name. | Typing the DB name for every cell edit would train users to type it reflexively, weakening the guard where it matters. |
| 33 | 2026-10-26 | Phase 4 UI: all writes go through `WriteGate` (App/Safety). Grid commits use `origin: .gridEdit`. ⌫ in the grid clears a cell (empty string for text columns, NULL otherwise); "Set to Default" only offers literal defaults (expression defaults like CURRENT_TIMESTAMP aren't evaluated client-side, except on inserted rows where the server fills them). After a conflict, "Reload, Keep My Edits" rebases each edit onto the fresh value (`EditSession.rebaseOriginal`). Pending edits survive sort/filter/paging; inserted rows show at the top of every page. | The server is the authority on defaults; a rebase is explicit so overwriting a colleague's change is a conscious choice. |
| 34 | 2026-10-26 | Query editor = our own TextKit 2 `NSTextView` subclass using Core's `SQLHighlighter`/`SQLCompletion` (no CodeEditSourceEditor). | CodeEditSourceEditor pulls tree-sitter and a large dependency graph for features Core already provides, tuned to MySQL/MariaDB/Postgres dialects; a small editor keeps the app lean and fully under our control. |
| 35 | 2026-10-26 | Query tabs run only through `QueryRunner` (prepare → `WriteGate.confirm` → run). ⌘↵ runs the selection or else everything, ⇧⌘↵ the statement at the caret. History re-runs, saved-query runs and AI-inserted SQL take the same path, so the PROD guard can't be skipped. Stop cancels between statements (the driver can't abort a running statement yet). Closing a query tab with unsaved *text* doesn't prompt; unsaved *result edits* do (same prompt as table tabs). | One execution path is the only way to make "never auto-run, always guarded" true. |
| 36 | 2026-10-26 | Editable query results reuse `TableDataModel` in a "fixed query" mode (`fixedQuery`): the grid, Review sheet, conflict handling and `WriteGate` origin `.gridEdit` are the table browser's. Columns are named as the base table's (aliases show the table column name), Add/Duplicate row are off, and read-only results sort client-side. | Reuse over a second edit stack; an edit model per result, only when `EditableResultAnalyzer` says the result maps to one table with its key. |
| 37 | 2026-10-26 | AI sample rows are a per-connection opt-in stored in `settings.json` (`ai.sampleRowsByConnection`, falling back to `includeSampleRowsByDefault`), forgotten when the connection is deleted. When on, up to 3 rows from the 4 tables most related to the question are sent. The assistant can only insert text into the editor; it has no session. | Row data can be personal; the choice belongs to the connection, and the privacy text sits next to the toggle. |
| 38 | 2026-10-26 | Query tab text and its saved-query link persist in `WorkspaceTab` (`queryText`, `savedQueryID`, additive and tolerant); the ⌘K switcher lists saved queries as "Saved: name". History/saved/snippet stores live in `QueryServices` (one per app); history stores are per connection. | Window restore isn't built yet, but the tab state is ready for it. |
| 39 | 2026-10-26 | Remote exports send the dump script over ssh stdin (`sh -s`); the DB password lives only in a umask-077 temp defaults/pgpass file removed by trap — never in argv or env on the server. MySQL transient exclusion = separate `--where` invocation for `<prefix>options` concatenated into one stream (Postgres: warning, transients included). Collation rewrite on remote-gzipped exports = decompress→rewrite→recompress locally. Gzip via system zlib. Postgres `COPY FROM stdin` blocks are imported as batched INSERTs. | Keeps secrets out of `ps` on shared hosts; one compressed file per export as the brief asks. |
| 40 | 2026-10-26 | Known limit: optimistic-concurrency checks (grid edits, search & replace) compare with the column's collation on MySQL, so a concurrent change only in letter case/trailing spaces isn't detected as a conflict. Byte-exact compare needs per-column charset handling; revisit if it matters in practice. | A wrong byte compare would produce false conflicts, which is worse for daily use. |
| 41 | 2026-10-26 | **SwiftTerm 1.11.2** (exact pin) for the SSH terminal tab. Newest releases are unusable here: 1.12–1.20 compile a Metal shader (needs the optional Xcode Metal Toolchain, absent on this Mac/CI) and 1.19+/1.99 add a build-tool plugin that needs plugin-validation bypass. 1.11.2 is the newest tag with neither; builds warning-free in our target. | Reproducible builds without extra Xcode components or weakening package-plugin validation. Revisit when we want newer terminal features. |
| 42 | 2026-10-26 | Terminal = `LocalProcessTerminalView` running `/usr/bin/ssh` with `SSHTerminalCommand` (shared client options, forced `-t`, no `BatchMode`, 3 password tries, `LogLevel=ERROR` first). Password/passphrase come from the Keychain through a temp `SSHAskpass` removed when the session ends or the tab closes; anything not stored is asked in the terminal. The view is owned by the model so the session survives tab switches. Disabled with an explanation for connections without SSH. | One SSH stack (#13); secrets never in argv. |
| 43 | 2026-10-26 | SQL console prompt: `mysql>` for MySQL/MariaDB (as in the design), `db=#` for PostgreSQL; the current database is in the header. Statements run through `QueryRunner` → `WriteGate` (cancelled confirmation prints "Cancelled.", read-only prints an `ERROR:`); results print mysql-client style tables (numbers right-aligned, cells truncated at a Settings width, newlines escaped), at most 1,000 rows per result (rest via "Open in grid", ⇧⌘G, which opens a query tab and runs the SQL there). `USE db` also moves the sidebar. `\c` clears the pending input, `clear` the screen. Light mode uses a light variant of the dark design. | Same guard path as the editor; the design's console is dark-only, the app has two themes. |
| 44 | 2026-10-26 | Export dialog is a thin form over `ExportPlanner`; the plan (and the redacted command preview) regenerates on every option change. Export asks for the destination with NSSavePanel when you press Export. WordPress transients are offered only when a table named `*options` has `option_name`/`option_value`. Local-tool problems (none found, older than server, flavour mismatch) show in amber with `brew install mysql-client` / `libpq`. | Exact preview = what runs. |
| 45 | 2026-10-26 | Import: pre-scan (first 512 MB) with the suggested mapping preselected; authorization reuses `WriteGate.confirm` with the guard's request relabelled `SOURCE '<file>'` (typed database name on PROD). Core gained `ImportOptions.onError` (async Continue/Stop hook when stop-on-error is off) and `ImportProgress.currentStatement`; the sheet pauses at each failing statement with Continue / Continue-don't-ask-again / Stop. Target database picker runs `USE`/`SET search_path` first. | Delivers the requested Continue/Stop without re-implementing the runner. |
| 46 | 2026-10-26 | Result export: table footer "Export…" re-reads the table with its current filters/sort page by page (`ResultExporter.exportTable`); query results export the selected in-memory result. CSV/JSON/SQL options in one sheet; a failed or cancelled run deletes the partial file. Dropping `.sql`/`.sql.gz`/`.gz` on a connection window opens Import. ⇧⌘E / ⇧⌘I are in File. | |
| 47 | 2026-10-26 | Snapshot note: MariaDB 11.4.5+ accepts MySQL's `utf8mb4_0900_*` names, so the import-scan fixture is a MariaDB 11.4 dump (`utf8mb4_uca1400_ai_ci`) imported into MySQL 8.4, a real incompatibility. | |
| 48 | 2026-10-26 | Export table selection: every table is structure + data by default (`ExportOptions.tableModes`, missing = both). The planner groups tables by mode into up to three dump invocations concatenated into one stream (normal / `--no-data` / `--no-create-info`; skipped = `--ignore-table`, or left out of an explicit list when most tables are skipped). Routines and events only in the first invocation; the transient split still applies to the options table. pg_dump: one run with `-T` and `--exclude-table-data`, plus a second `--data-only -t` run only for data-only tables. | One file, exact preview, no plugin knowledge needed. |
| 49 | 2026-10-26 | Grouping is automatic and plugin-agnostic: WordPress core = the fixed core set under the detected prefix (incl. multisite); every other table is clustered by the leading token after the prefix when ≥2 tables share it (`wp_actionscheduler_*`), then by the longest common stem (≥2 chars, ≥2 tables) for names without an underscore (`wp_wf*`); the rest are "Other tables". Non-WordPress schemas use the same clustering without a core group. `WordPressTableCatalog` only adds friendly names and a precise list of known log/cache tables. | Far too many plugins to enumerate; a pattern is always a usable rule. |
| 50 | 2026-10-26 | Suggestions ("Suggest: structure only" + reason) come from generic name heuristics (`*_log(s)`, `*_sessions`, `*_cache`, `*_transient*`, `*_queue`, `*_events`, `*_hits`, `*_stats`, `*_tmp/_temp`, `*log` stems) first and the curated list second; never applied automatically ("Apply suggestions (N)"). Presets (All tables / WordPress core only / Core + plugin structure only) are bulk mode-setters. | Low effort without silently dropping data. |
| 51 | 2026-10-26 | `ExportSelectionRules` (`export-rules.json`, 0600, atomic, per connection; purged with the connection): ordered glob rules (last match wins, case-insensitive, `*`/`?`) plus the explicit per-table choices of the last export, which beat rules. "Remember as rule" saves the filter text (plain text becomes `*text*`); rules show as removable chips and also catch tables added later. | Excluding e.g. `wp_wf*` once is enough. |
| 52 | 2026-10-26 | Distribution: direct download only (DMG + zip), Developer ID signed, notarized and stapled; not sandboxed; hardened runtime on. Entitlements stay at `com.apple.security.app-sandbox = false` and nothing else. `scripts/release.sh` fails if the signed app carries any other entitlement (e.g. an injected `get-task-allow`, which it also disables with `CODE_SIGN_INJECT_BASE_ENTITLEMENTS=NO`). | Needs to launch `ssh`, `mysqldump`, `pg_dump`. Hardened runtime needs no exceptions: subprocesses, Keychain and outbound network work as-is, no JIT. |
| 53 | 2026-10-26 | No `disable-library-validation` entitlement. The only embedded Mach-O besides the app binary is Swift's back-deploy `Frameworks/libswiftCompatibilitySpan.dylib`; all SwiftPM products (QuerywellCore, SwiftTerm, NIO) link statically. Xcode re-signs the dylib with our team, so library validation passes. The release script verifies every Mach-O in the bundle for team ID, hardened runtime and secure timestamp, so a future dynamic framework signed differently fails the build instead of the user's launch. | Keeps library validation (a security feature) on. |
| 54 | 2026-10-26 | `release.sh` notarizes twice: the app first (zipped), which is stapled, then the DMG built from the stapled app (which is stapled too). The zip is made after stapling. | A single DMG submission leaves the app inside the DMG without its own ticket, so it only passes Gatekeeper online after being dragged out. The cost is a second notarization wait. |
| 55 | 2026-10-26 | Version 1.0.0 (build 1) for v1, via `MARKETING_VERSION`/`CURRENT_PROJECT_VERSION` in `project.yml`; `scripts/bump-version.sh <version> [build]` edits both (build defaults to current + 1). Release builds are universal (arm64 + x86_64, Xcode's standard architectures). | One place for the version; Intel Macs on macOS 14-15 are still supported by the deployment target. |
| 56 | 2026-10-26 | App icon placeholder is the classic `AppIcon.appiconset` (16-512 @1x/@2x PNGs, 824pt rounded square on the 1024 grid, accent `#2459D6` database cylinder with a `>_` prompt on a light ground), generated by `scripts/make-icon.swift` (CoreGraphics, no third-party tools). Not an Icon Composer `.icon`: that format is only needed for macOS 26 Liquid Glass layered icons and can replace this later; macOS 26 renders classic icons inside its standard tile treatment. | Reproducible placeholder with zero actool warnings; final art is a design task. |
